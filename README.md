# 🍽️ Restaurant Website

A modern and responsive **restaurant website** built with HTML and CSS, designed to present a restaurant's menu, services, and visual identity through a clean and user-friendly interface.

🔗 **Live Demo:**
https://khaledhelmyg.github.io/reastorant-app/

## ✨ Features

* 🍴 Restaurant-focused landing page
* 📋 Menu and food presentation
* 🖼️ Food and restaurant imagery
* 📱 Responsive layout
* 🎨 Custom CSS styling
* 📄 Dedicated website pages
* ⚡ Lightweight static website
* 🌐 Deployable through GitHub Pages

## 🛠️ Tech Stack

| Technology   | Purpose                       |
| ------------ | ----------------------------- |
| HTML5        | Page structure                |
| CSS3         | Styling and responsive layout |
| GitHub Pages | Static website deployment     |

## 📁 Project Structure

```text
reastorant-app/
│
├── css/
│   └── stylesheets
│
├── images/
│   └── restaurant & food assets
│
├── pages/
│   └── additional website pages
│
├── favicon.png
├── index.html
└── README.md
```

The repository currently contains separate `css`, `images`, and `pages` directories together with the main `index.html` entry point.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/khaledhelmyg/reastorant-app.git
```

```bash
cd reastorant-app
```

### Run locally

Because this is a static website, no backend or package installation is required.

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, you can also use a local development server such as VS Code Live Server.

## 🌐 Deployment

The project is currently deployed using **GitHub Pages**.

Live website:

https://khaledhelmyg.github.io/reastorant-app/

Any updates pushed to the configured GitHub Pages branch can be published through the repository's deployment configuration.
